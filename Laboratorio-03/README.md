## Cómo ejecutar

Entra a la carpeta del ejercicio y ejecuta su archivo:

```bash
cd practica-3-1
python cotizador_funciones.py        # (o py / python3)

cd ../practica-3-2/01_dos_modulos
python main.py
```

En `practica-3-2` cada ejercicio vive en su subcarpeta porque varios usan un
`main.py` distinto.

Las respuestas a las preguntas de predicción están como comentarios dentro
de los archivos.
